# Dragon ModZ mod builder

Builds a custom-item Fabric mod for any Minecraft version from 1.14.4 to 26.3.

1. Open the Actions tab, pick "Build a mod" on the left, click "Run workflow".
2. Choose the Minecraft version, fill in the item, click the green Run workflow button.
3. When the run turns green, open it, scroll to Artifacts and download the jar.

You also need Fabric Loader and Fabric API for that Minecraft version in your game.
